
# 🧠 Proyecto Final - Juego de Preguntas (React + Supabase)

Este proyecto es una aplicación de preguntas y respuestas construida con **React**, **Vite**, **Zustand**, **TanStack (React Query)** y **Supabase** como base de datos.  
Es el proyecto final para completar un curso de Udemy.

Repositorio: [https://github.com/Nicolettastr/zustand_tanstack_final_project_player.git](https://github.com/Nicolettastr/zustand_tanstack_final_project_player.git)

---

## 🚀 Tecnologías utilizadas

- [Vite](https://vitejs.dev/) – Empaquetador rápido para frontend moderno
- [React](https://react.dev/) – Librería para construir interfaces
- [Zustand](https://zustand-demo.pmnd.rs/) – Manejo global de estado
- [TanStack React Query](https://tanstack.com/query/latest) – Manejo de datos y caché
- [Supabase](https://supabase.com/) – Backend como servicio (BaaS)

---

## ⚠️ Nota importante

> Debido al uso gratuito y ocasional del servicio, **Supabase puede entrar en modo de suspensión ("cold start")**.  
> Si el proyecto parece no cargar correctamente al principio, espera unos segundos o recarga la página para reactivar el backend.

---

## 🧩 Funcionalidades

- Listado dinámico de preguntas y respuestas
- Persistencia de datos en Supabase
- Manejo del estado global con Zustand
- Fetching y cacheo eficiente con TanStack React Query
- UI interactiva y rápida gracias a Vite y React
